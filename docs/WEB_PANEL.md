# Web 面板使用

登录后，首页按 Server 保存的顺序展示设备。默认只展开第一台设备；设备在线时显示系统运行时间，离线时隐藏运行时间并把指标卡片中的动态值归零。主机名、系统、架构、IP 和 Agent 版本等静态详情会继续保留，便于确认离线设备身份。

## 1. 查看与操作设备

点击设备右侧“详情”展开内容。桌面端每行显示 3 张等尺寸指标卡片，默认共 6 张；窄屏会严格变成单列，不会出现两列挤压。

设备在线时可以使用当前 Server 和 Agent 均已开启的操作：

- 执行命令
- 终端
- 文件
- 重启
- 关机

IP 地址右上角的复制图标会复制该设备当前上报的全部 IP。Terminal 所需的 xterm.js、FitAddon 和样式已随 Server 内置，不依赖外部 CDN。

## 2. 调整设备顺序

首页设备卡片和“设备管理”列表左侧都有六点手柄 `⠿`。只有按住这个手柄才能排序；设备卡片、名称输入框、“详情”“终端”“文件”等区域不会触发拖动。

拖动时会显示跟随指针的浮动中间态和目标占位区域。把指针移动到列表内的目标位置后松开即可保存；在列表外松开或系统取消手势会恢复原顺序。修改设备名称不会改变顺序。

## 3. 设置某台设备的指标卡片

打开“设备管理”，在目标设备所在行点击“指标卡片”。下方蓝色“当前设备”区域会立即显示所选设备的名称、ID 和在线状态，用来确认设置对象；六点手柄只负责排序，不负责切换设置对象。

勾选需要的指标卡片后自动保存：

- CPU 与温度
- 内存
- 存储
- 网络吞吐
- 进程 / 任务
- 磁盘 I/O

每台设备至少保留 3 张。在线 Agent 会立即收到策略并停止采集、上报被隐藏卡片对应的动态信息；离线设备会在下次连接时收到。网络和磁盘 I/O 需要相邻两次采样才能计算速率，因此刚启用时第一次显示 0 属正常现象。

## 4. 管理设备

“设备管理”还可以：

1. 点击“添加设备”，填写可选的自定义名称并生成一次性 Agent Token。该名称会保留原始大小写；留空才回退到 Agent 名称或 hostname。
2. 修改名称后点击同行“保存”。名称更新不会改变手动顺序。
3. 点击“删除”吊销该设备的长期 Device Token 并断开连接。重新添加前需要在 Agent 端删除旧 `state.json`，再使用新的 Enrollment Token。

## 5. 主题与账户

顶部主题控件支持暗色、亮色和跟随系统三种模式，并保存在当前浏览器。窄屏时它与“设备管理”“账户”“退出”一起位于右上角操作面板。

“账户”用于修改用户名、密码和 TOTP 两步验证。修改认证信息会要求重新登录；密码和 TOTP Secret 不会保留在关闭后的表单中。
